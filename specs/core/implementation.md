# Implementacja aplikacji

## Wymagania

- Aplikacja ma zostać zaimplementowana zgodnie z testami Python znajdującymi się w katalogu `specs`.
- Komplet testów specyfikacji ma przechodzić poprawnie.
- Repozytorium Git ma ignorować artefakty kompilacji i testów, ustawienia IDE, środowisko Python oraz lokalny plik `.env` zawierający dane uwierzytelniające.
- Aktualne zmiany aplikacji mają zostać zatwierdzone w Git i wysłane do gałęzi `main` zdalnego repozytorium `origin`.
