# Aplikacja .NET z logowaniem

## Wymagania

- Aplikacja ma być utworzona jako aplikacja webowa ASP.NET Core MVC.
- Aplikacja ma używać .NET 10 LTS.
- Aplikacja ma używać wzorca MVC i renderować interfejs po stronie serwera.
- Interfejs aplikacji ma być w języku angielskim.
- Konfiguracja i dane uwierzytelniające nie mogą być zapisane na stałe w kodzie.
